
# MeasureMate ✂️
### Measure. Create. Perfect.

MeasureMate is a digital sewing companion designed to help amateur seamstresses, dressmakers and home-based sewing businesses manage measurements, maintain client records and organise sewing projects.

## About the Project

Many seamstresses rely on physical notebooks or diaries to record body measurements and client information.

Although this traditional method works, it can become inconvenient when a notebook is misplaced, forgotten at home or unavailable when a returning client needs another garment.

MeasureMate aims to solve this problem by providing a digital measurement record book where users can organise, store, update and retrieve measurement information.

The application also brings together practical sewing tools to make everyday sewing activities easier and more organised.

## The Problem MeasureMate Solves

Traditional measurement record-keeping can result in:

- Lost or misplaced client measurements.
- Difficulty retrieving previous records.
- Repeated measuring when old records are unavailable.
- Disorganised client information.
- Time wasted searching through handwritten notebooks.

MeasureMate aims to provide a convenient digital alternative.

## Key Features

### 1. Measurement Tracker – Digital Measurement Record Book

The central feature of MeasureMate.

Planned functionality includes:

- Creating individual client profiles.
- Recording body measurements.
- Editing and updating measurements.
- Searching for clients by name.
- Retrieving previously saved measurements.
- Recording measurement dates.
- Adding fitting notes.
- Maintaining measurement histories.

Measurements will include bust, waist, hips, shoulders, neck, armhole, sleeve length, dress length, skirt length, trouser length and custom measurements.

### 2. Unit Converter

Convert between centimetres (cm) and inches (in).

### 3. Pattern Size Guide

Compare body measurements with sewing pattern size charts to help users select appropriate pattern sizes.

### 4. Sewing Project Planner

Organise sewing projects, materials, deadlines, client information and project progress.

### 5. Seam Allowance Calculator

Assist with common seam allowance calculations and measurement conversions.

### 6. Fabric Estimator

Help users estimate fabric requirements for different sewing projects.

### 7. Visual Sewing Guides

Provide visual references to support users with taking measurements and learning sewing techniques.

### 8. Data Storage and Backup

Future development aims to introduce reliable data storage and backup, with potential access across multiple devices.

## Installation and Usage

1. Download or clone the repository.
2. Extract the project files.
3. Keep all application files in the same directory.
4. Open `index.html` in a web browser.

The project can also be edited using Visual Studio Code or Acode.
